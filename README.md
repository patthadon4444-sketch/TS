# Game Translator (Android)

แอปแปลข้อความบนหน้าจอเกมแบบเรียลไทม์ อังกฤษ → ไทย
เลือกแอป/เกมก่อน → แอปจะแปลเฉพาะตอนที่เกมนั้นอยู่หน้าจอ → ชื่อตัวละครที่ใส่ไว้ไม่ถูกแปล

ต้องใช้ Android 8.0 ขึ้นไป

## วิธีได้ไฟล์ติดตั้ง (.apk) แบบไม่ต้องลง Android Studio

1. สมัคร/ล็อกอิน github.com แล้วสร้าง repository ใหม่ (ตั้งเป็น Private ได้)
2. แตก zip นี้ แล้วอัปโหลดไฟล์ทั้งหมดขึ้น repository (รวมโฟลเดอร์ `.github` ด้วย)
   ถ้าอัปโหลดผ่านเว็บแล้วโฟลเดอร์ `.github` ไม่ขึ้น ให้ใช้ GitHub Desktop หรือ git แทน
3. ไปที่แท็บ **Actions** → เลือก **Build APK** → กด **Run workflow** (ถ้ายังไม่รันเอง)
4. รอประมาณ 5-10 นาที เปิดงานที่เสร็จ แล้วโหลดไฟล์ **GameTranslator-APK** ในหัวข้อ Artifacts
5. แตก zip ได้ `app-debug.apk` ส่งเข้ามือถือแล้วติดตั้ง (ต้องอนุญาต "ติดตั้งแอปจากแหล่งที่ไม่รู้จัก")

ถ้ามี Android Studio อยู่แล้ว: เปิดโฟลเดอร์นี้ → Build → Build APK(s)

## วิธีใช้

1. เปิดแอป → กด **เลือกแอป** เลือกเกม
2. ตั้ง **พื้นที่อ่าน** ให้ครอบกล่องบทพูดของเกม (เช่น เริ่มที่ 55% ถึง 100% = ครึ่งล่างของจอ)
   และตั้ง **ตำแหน่งแถบคำแปล** ไว้คนละฝั่ง (เช่น บทพูดอยู่ล่าง ก็ให้แถบคำแปลอยู่บน)
3. เลือกตัวแปล
   - **ML Kit**: ฟรี ออฟไลน์ (โหลดโมเดลครั้งแรกต้องใช้เน็ต ~30MB) คุณภาพพอใช้
   - **Gemini / Claude**: ต้องใส่ API key คำแปลลื่นกว่าและเข้าใจบริบทเกมดีกว่า
4. ใส่ชื่อตัวละครที่ไม่ต้องแปล (1 ชื่อต่อ 1 บรรทัด)
5. กด **เริ่มแปล** → อนุญาตสิทธิ์ที่แอปขอ (แสดงทับแอปอื่น, การเข้าถึงข้อมูลการใช้งาน, แชร์หน้าจอ)
   แต่ละครั้งที่ขอสิทธิ์ใหม่ ให้กดย้อนกลับมาที่แอปแล้วกด **เริ่มแปล** อีกรอบ
6. ตอนแชร์หน้าจอ ให้เลือก **ทั้งหน้าจอ** แอปจะเปิดเกมให้เอง
7. หยุดได้จากปุ่มในแอป หรือปุ่ม "หยุด" ในแจ้งเตือน

## ข้อจำกัด

- บางเกมบล็อกการจับภาพหน้าจอ (FLAG_SECURE) จะได้ภาพดำและแปลไม่ได้
- OCR อ่านได้เฉพาะข้อความภาษาอังกฤษ ฟอนต์ตกแต่งหรือพื้นหลังลายเยอะอาจอ่านผิด
- ใช้ ML Kit แล้วชื่อตัวละครอาจหลุดบ้างในประโยคซับซ้อน ถ้าต้องการให้แม่นขึ้นให้ใช้ Gemini หรือ Claude
- API key เก็บในที่เก็บส่วนตัวของแอปบนเครื่อง ไม่ได้ส่งไปที่อื่นนอกจากผู้ให้บริการที่เลือก
- ไฟล์ .apk จาก workflow เป็นแบบ debug เหมาะสำหรับติดตั้งใช้เอง
